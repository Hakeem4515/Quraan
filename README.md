## 🌟 Overview

**Quraan** is a modern Quran application designed to provide a comfortable and immersive reading experience.

The application combines a **Mushaf-inspired reading interface** with modern mobile UI principles, allowing users to navigate the Quran easily while keeping track of their reading progress.

The goal is to create a simple, beautiful and distraction-free Quran reading experience.

---

## ✨ Features

### 📖 Quran Reading

- Complete Quran reading experience
- Mushaf-inspired page interface
- Accurate Quran page numbering
- Accurate verse ranges for each page
- Surah-based navigation
- Horizontal page navigation
- Vertical reading mode
- RTL optimized interface
- Smooth reading experience

### 🎨 Reading Customization

- Multiple Quran page interface styles
- Adjustable font size
- Quran font customization
- Custom reading preferences
- Light and dark reading experiences
- Clean and minimal interface

### 📊 Khatma

- Start a new Quran Khatma
- Track reading progress
- Save Khatma progress locally
- Continue reading from the last Khatma position
- Separate normal reading position from Khatma progress

### 🔖 Reading Progress

- Remember the user's last reading position
- Resume reading from the previous location
- Page-based Quran navigation
- Surah and Ayah based positioning

### ⚙️ Settings

- Reading preferences
- Font settings
- Display settings
- Navigation settings
- Customizable Quran reading experience
